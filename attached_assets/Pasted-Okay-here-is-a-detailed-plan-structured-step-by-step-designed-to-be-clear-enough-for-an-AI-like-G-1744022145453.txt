Project Goal: Create a web application using Flask and standard web technologies (HTML, CSS, JS) to allow users to upload one or more CSV or Excel files, have the backend merge and clean the data using Pandas, and then allow the user to download the cleaned data as a single Excel file.

Core Technologies:

Backend: Python, Flask, Pandas, Openpyxl

Frontend: HTML, CSS, JavaScript (Vanilla JS with Fetch API)

Phase 3: Backend - API Endpoints

Implement Upload Endpoint (backend/app.py):

Define route @app.route('/upload', methods=['POST']).

Inside the route function:

Check if 'files' (matching the frontend input name) is in request.files. If not, return jsonify({'error': 'No file part'}), 400.

Get the list of files: files = request.files.getlist('files').

Initialize saved_files_paths = [].

Check if files list is empty or contains only files with empty filenames. If so, return jsonify({'error': 'No selected file'}), 400.

Iterate through the files:

For each file:

If file and allowed_file(file.filename):

Sanitize filename: filename = secure_filename(file.filename)

Create full save path: filepath = os.path.join(app.config['UPLOAD_FOLDER'], filename)

Save the file: file.save(filepath)

Append filepath to saved_files_paths.

Else (if file not allowed):

Log or note the invalid file type (optional).

If saved_files_paths is empty (no valid files were saved), return jsonify({'error': 'No valid files uploaded'}), 400.

Call Data Loader: merged_df = data_loader.load_and_merge_data(saved_files_paths)

Handle merged_df being None (loading failed): Return jsonify({'error': 'Failed to load or merge files'}), 500.

Call Data Cleaner: cleaned_df = cleaner.clean_data(merged_df)

Handle potential errors during cleaning (if clean_data might fail).

Save Cleaned Data:

Define output filename: output_filename = "cleaned_data.xlsx"

Define full output path: output_path = os.path.join(app.config['OUTPUT_FOLDER'], output_filename)

Use a try-except block for saving.

Save to Excel: cleaned_df.to_excel(output_path, index=False, engine='openpyxl')

If saving successful: Return jsonify({'message': 'Files processed successfully', 'download_filename': output_filename}), 200.

If saving failed: Return jsonify({'error': 'Failed to save cleaned file'}), 500.

Cleanup (Optional but Recommended): Delete the uploaded files from uploads/ after successful processing. Loop through saved_files_paths and use os.remove(path).

Implement Download Endpoint (backend/app.py):

Define route @app.route('/download/<filename>', methods=['GET']).

Inside the route function:

Use send_from_directory: return send_from_directory(app.config['OUTPUT_FOLDER'], filename, as_attachment=True)

Add error handling (e.g., try-except FileNotFoundError) in case the file doesn't exist.
